A Spanish Civil War mod for [Armoured Commander II](https://armouredcommander.com/).

# Installation

Place the Spanish Civil War folder in your mod directory. On Windows systems, this is usually `%USERPROFILE%\ArmCom2\mods`. On macOS and Linux, this may be `~/ArmCom2/mods` or the mods folder in the game's install directory.

# Issues and Contributions

If you notice something that should be corrected (like a unit having inaccurate weaponry or showing up in the wrong time period), feel free to [submit a PR](https://github.com/saintmuntzer/ac2-spanishcivilwar/pulls) or [open an issue](https://github.com/saintmuntzer/ac2-spanishcivilwar/issues).

# References

A number of sources are used as the historical basis for vehicles and weaponry in this mod, including:

[Aircraft of the Spanish Civil War](https://web.archive.org/web/20150205085135/http://www.zi.ku.dk/personal/drnash/model/Spain/did.html)

[Sociedad Benéfica de Historiadores Aficionados y Creadores](https://www.sbhac.net/Republica/Fuerzas/Fuerzas.htm)

[Tank Encyclopedia](https://tanks-encyclopedia.com/)

[Vehiculos Blindados de la Guerra Civil](https://vehiculosblindadosdelaguerracivil.blogspot.com/)
